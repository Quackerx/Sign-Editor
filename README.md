# SIGN EDITOR GUIDE
- **ALL Buttons are in the inventory GUI**

## WHAT EACH BUTTON DOES
- **No Render**: Stops rendering the sign text _(prevents lag)_
- **Auto Sign**: Automatically edits the sign with the configured settings
- **Custom**: When enabled, you can enter your custom text for the sign! Else it will fill it up with random characters.
- **Back**: When enabled, it also adds the text to back of the sign, else it wont.
- **MAX**: When enabled, it will make a sign as **big as possible**
- **Black Box with 80 (or number)**: A *length* box. This determines how long each line is on the sign. **80 = 80 characters** _(Paper only supports 80)_
